# Minimum Operations

This project contains a function to compute the minimum number of operations required to get exactly `n` 'H' characters in a file, using only Copy All and Paste operations.

## Files
- `0-minoperations.py`: Contains the `minOperations(n)` function.

## Function Prototype
```
def minOperations(n):
	"""Returns the fewest number of operations needed to result in exactly n H characters."""
```

## Usage Example
```
$ cat 0-main.py
#!/usr/bin/python3
minOperations = __import__('0-minoperations').minOperations
print(minOperations(4))  # Output: 4
print(minOperations(12)) # Output: 7
```
